# 🛡️ IP Check to docx

Автоматизированный инструмент для проверки IP-адресов по Threat Intelligence платформам с формированием отчёта в формате `.docx`.

Программа предназначена для быстрого анализа подозрительных IP-адресов и подготовки уведомлений для специалистов по информационной безопасности.

---

## 📌 Возможности

- Проверка IP-адресов через:
  - VirusTotal API
  - AbuseIPDB API

- Получение информации:
  - страна расположения IP-адреса;
  - провайдер;
  - категории нарушений AbuseIPDB;
  - количество срабатываний TI-вендоров VirusTotal;
  - список антивирусных движков, обнаруживших угрозу.

- Автоматическое определение наиболее подозрительного IP-адреса.

- Формирование отчёта:
  - создание документа Microsoft Word (`.docx`);
  - таблица с IP-адресами и странами;
  - описание наиболее вредоносного адреса.

---

## 🖥️ Пример работы

Пользователь вводит список IP-адресов:

```
8.8.8.8
185.xxx.xxx.xxx
45.xxx.xxx.xxx
```

После проверки создаётся документ:

```
Отчёт о вредоносных IP-адресах 26-07-2026 14-30.docx
```

В отчёте содержится:

- список проверенных IP;
- страны целевых адресов;
- описание угроз;
- результаты анализа VirusTotal;
- категории активности AbuseIPDB.

# ⚙️ Установка

## 1. Клонирование репозитория

```bash
git clone https://github.com/Helinqwe/ip-check-to-docx.git

cd ip-check-to-docx
```

---

## 2. Установка зависимостей

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его:

### Windows

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

---

# 🔑 Настройка API ключей

Для работы программы необходимы API ключи:

- VirusTotal API Key
- AbuseIPDB API Key


Создайте файл:

```
.env
```

В корне проекта:

```
VT_API_KEY=ваш_ключ_VirusTotal
ABUSEIPDB_API_KEY=ваш_ключ_AbuseIPDB
```

Программа автоматически загрузит ключи через `python-dotenv`.

---

# 🚀 Запуск

Запустите:

```bash
python "docx_ip_check v1.0.py"
```

После запуска появится окно ввода IP-адресов.

Введите IP-адреса через перенос строки или через пробел:

```
1.1.1.1
8.8.8.8
```

После завершения проверки в папке проекта появится DOCX-отчёт.
